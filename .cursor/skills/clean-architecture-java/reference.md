# Справочник: метрики и принципы компонентов

## Метрики устойчивости (SDP)

- **Fan-in**: количество классов вне компонента, зависящих от классов внутри компонента (входящие зависимости).
- **Fan-out**: количество классов внутри компонента, зависящих от классов снаружи (исходящие зависимости).
- **I (неустойчивость)**: I = Fan-out / (Fan-in + Fan-out). Диапазон [0, 1]. I = 0 — максимально устойчивый компонент; I = 1 — максимально неустойчивый.

**Принцип устойчивых зависимостей (SDP):** зависимость должна быть направлена от компонента с большим I к компоненту с меньшим I (в сторону устойчивости).

## Метрики абстрактности (SAP)

- **Nc**: число классов в компоненте.
- **Na**: число абстрактных классов и интерфейсов в компоненте.
- **A (абстрактность)**: A = Na / Nc. Диапазон [0, 1].

**Принцип устойчивости абстракций (SAP):** устойчивый компонент должен быть абстрактным (интерфейсы, абстрактные классы), чтобы расширение шло через наследование, а не через изменение кода.

## Главная последовательность

На графике (I по горизонтали, A по вертикали) «хорошие» компоненты лежат вблизи главной последовательности: устойчивые — абстрактные (левый верх), неустойчивые — конкретные (правый нижний угол). Компоненты в «запретных» зонах (устойчивые и конкретные или неустойчивые и абстрактные) — кандидаты на рефакторинг.

## Разрыв циклов зависимостей (ADP)

- **Инверсия зависимостей (DIP):** ввести интерфейс в одном из компонентов цикла и реализацию в другом так, чтобы зависимость по исходному коду развернулась и цикл исчез.
- **Новый компонент:** вынести общую абстракцию (интерфейс) в отдельный компонент; оба циклически зависимых компонента начинают зависеть от него.
