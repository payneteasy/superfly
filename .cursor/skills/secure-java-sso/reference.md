# Ссылки и материалы: безопасность Java и SSO

## OWASP Cheat Sheet Series

- [Authentication Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html) — пароли, MFA, сброс пароля, учёт блокировок.
- [Session Management Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html) — генерация ID, cookie, таймауты, фиксация сессии.
- [Java Security Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Java_Security_Cheat_Sheet.html) — инъекции, валидация, десериализация, безопасная конфигурация.
- [OAuth 2.0 Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/OAuth2_Cheat_Sheet.html) — PKCE, state, redirect_uri, конфиденциальность клиентов.
- [SAML Security Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/SAML_Security_Cheat_Sheet.html) — подписание, шифрование, защита от подмены утверждений.
- [JSON Web Token for Java](https://cheatsheetseries.owasp.org/cheatsheets/JSON_Web_Token_for_Java_Cheat_Sheet.html) — выбор библиотеки, проверка подписи, алгоритм "none".
- [Secrets Management Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Secrets_Management_Cheat_Sheet.html) — хранение и ротация секретов.

## Стандарты

- RFC 9700 (OAuth 2.0 Security BCP) — актуальные практики безопасности OAuth 2.0.
- NIST SP 800-63B — рекомендации по паролям и уровням уверенности аутентификации.
