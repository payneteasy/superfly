Add micrometer-registry-prometheus to your classpath and expose the /actuator/prometheus endpoint, then configure Prometheus:

# prometheus.yml
scrape_configs:
  - job_name: superfly
    static_configs:
      - targets: ['<host>:8080']
    metrics_path: /actuator/prometheus
    scrape_interval: 15s

Useful PromQL queries:

  • Total call rate: rate(sso_call_duration_seconds_count[1m])
  • Error rate per operation: rate(sso_call_duration_seconds_count{status="error"}[5m])
  • P99 latency: histogram_quantile(0.99, rate(sso_call_duration_seconds_bucket[5m]))
  • Time since last success (seconds): time() - sso_last_success_epoch_ms / 1000

Import the Superfly SSO dashboard into Grafana:

  1. Open Grafana → Dashboards → Import
  2. Upload grafana/superfly-sso-dashboard.json from the project repo
  3. Select the Prometheus datasource pointing to your Superfly instance

Recommended alert rules:

  • Error rate > 10% for 5 minutes → rate(sso_call_duration_seconds_count{status="error"}[5m]) / rate(sso_call_duration_seconds_count[5m]) > 0.1
  • No successful calls for 10 minutes → time() - sso_last_success_epoch_ms / 1000 > 600
  • P99 latency > 2 s → histogram_quantile(0.99, rate(sso_call_duration_seconds_bucket[5m])) > 2
